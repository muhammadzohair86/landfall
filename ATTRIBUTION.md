# Third-party attributions

## Photography

The sample photographs in `src/assets/images/` come from the Hepta template by Free-Template.co
(https://free-template.co/). The original bundle credited the author in its footer and did not include the
licence text, so please confirm the current terms on the author's site before commercial use.

That credit is kept on the website's Credits page (`/credits`), linked from the footer. Please keep it while
these photographs are in use. If you replace them with your own or separately licensed images, you can remove
this section and the Credits page entry.

The photographs were resized and recompressed for the web. No code, markup, styles or copy from that template
are used in this project.

Only a few images show identifiable places (Santorini, Cape Town, Iceland, New York). The rest are generic
scenes, so the website labels them as illustrative and does not name a location for them.
